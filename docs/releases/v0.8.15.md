# Kraken v0.8.15 Release Notes

**Release Date**: January 21, 2026

## Overview

Kraken 0.8.15 delivers **Iterators & Ranges**: A comprehensive implementation of range types and for-in loops with range pattern matching. This release provides efficient iteration constructs with both exclusive and inclusive range syntax, establishing the foundation for future iterator trait implementations.

## Range Types

### Core Features

- **Range Syntax**: `0..10` (exclusive), `0..=10` (inclusive)
- **Range Expressions**: First-class expressions that can be used anywhere
- **AST Representation**: `Expression::Range { start, end, inclusive }`
- **Lexer Support**: New `..` and `..=` operators
- **Type Checking**: Validates integer bounds for range start and end
- **LLVM Codegen**: Efficient range-based loop generation

### Range Operators

- **Exclusive Range (`..`)**: `0..10` iterates from 0 to 9
- **Inclusive Range (`..=`)**: `0..=10` iterates from 0 to 10
- Both operators work with any integer expressions

## For-In Loops

### Features

- **For-In Syntax**: `for (x in 0..10) { ... }`
- **Iterator-Based**: Clean syntax for range iteration
- **AST**: `Statement::ForIn { variable, iterable, body }`
- **Parser**: Automatically detects for-in vs C-style for loops
- **Type Checking**: Proper scope management for loop variables
- **IR Lowering**: Desugared to while loops with counter variables
- **LLVM Codegen**: Efficient loop structure (condition, body, increment blocks)
- **Break/Continue**: Full support for loop control flow

### Examples

```kraken
// Basic exclusive range
for (i in 0..5) {
    puts(i);  // Prints 0, 1, 2, 3, 4
}

// Inclusive range
for (i in 0..=5) {
    puts(i);  // Prints 0, 1, 2, 3, 4, 5
}

// Range with operations
let sum: int = 0;
for (i in 1..=5) {
    sum = sum + i;  // Computes 1+2+3+4+5 = 15
}

// Nested loops
for (i in 0..3) {
    for (j in 0..3) {
        puts(i * 3 + j);
    }
}
```

## Range Patterns

### Features

- **Range Pattern Syntax**: `0..10 -> { ... }`, `0..=10 -> { ... }`
- **AST**: `Pattern::Range { start, end, inclusive }`
- **Parser Support**: Integrated into match expression pattern parsing
- **Type Checking**: Validates int bounds and expression type
- **LLVM Codegen**: Efficient comparison logic (`>= start && < end`)

### Examples

```kraken
match (x) {
    0..10 -> {
        puts("Single digit");
    }
    10..100 -> {
        puts("Two digits");
    }
    100..=999 -> {
        puts("Three digits (inclusive)");
    }
    _ -> {
        puts("Other");
    }
}
```

## Implementation Details

### For-In Loop Desugaring

For-in loops are currently desugared to while loops:

```kraken
// Source
for (i in 0..10) { body }

// Desugared to (conceptually)
{
    let i: int = 0;
    while (i < 10) {
        body;
        i = i + 1;
    }
}
```

This approach provides efficient iteration without requiring a full trait system. Future versions will migrate to trait-based iterators.

## Roadmap Updates

### Iterator Trait Deferred

The full iterator trait/protocol has been deferred to **0.8.20** (Traits milestone) where it will be properly implemented with:
- `trait Iterator { type Item; fn next(&mut self) -> Option<Self::Item>; }`
- Range iterator implementation
- Array iterator implementation
- For-in loop desugaring to iterator protocol
- Iterator adapter methods (`map`, `filter`, `fold`, `collect`)

### Upcoming Milestones

- **0.8.16** — Advanced Patterns & Exhaustiveness
- **0.8.17** — Struct Patterns & Advanced Destructuring
- **0.8.18** — Operator Desugaring & Error Handling
- **0.8.19** — Closures & Lambdas
- **0.8.20** — Traits, Operator Overloading & Standard Traits (includes Iterator trait)

## Known Limitations

- Negative numbers in range patterns require parentheses (parser limitation)
- Range patterns only support integer types
- No iterator trait yet (deferred to 0.8.20)
- For-in loops only work with ranges (arrays/collections deferred)
