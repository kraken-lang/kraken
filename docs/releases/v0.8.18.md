# Kraken v0.8.18 Release Notes
**Release Date**: January 22, 2026

## Overview

Kraken v0.8.18 introduces **Operator Desugaring & Error Handling** infrastructure, laying the foundation for advanced error propagation patterns. This release adds full compiler support for the `?` operator syntax and establishes a comprehensive AST desugaring framework for future operator transformations.

This milestone focuses on building robust error handling capabilities using Result and Option enums, providing developers with powerful tools for managing errors in a type-safe manner.

---

## Core Features

### 1. **`?` Operator Infrastructure**

The `?` operator (try operator) is now fully supported throughout the compiler pipeline:

```kraken
// Result enum for error handling
enum Result {
    Ok(int),
    Err(int),
}

// Option enum for nullable values
enum Option {
    Some(int),
    None,
}

// Functions returning Result
fn divide(a: int, b: int) -> Result {
    if (b == 0) {
        Result::Err(1);
    } else {
        Result::Ok(a / b);
    }
}
```

**Key Components**:
- **AST Support**: New `Expression::Try { expression }` variant
- **Lexer Token**: `TokenKind::Question` for `?` character
- **Parser**: Postfix `?` operator parsing in expression chains
- **Type Checker**: Validation of Result/Option types
- **All Compiler Passes**: Full support in monomorphization, modules/loader, IR lowering, and LLVM codegen

### 2. **AST Desugaring Framework**

A new desugaring infrastructure enables transformation of high-level syntactic constructs:

```rust
// New AstDesugar module in analyzer
pub struct AstDesugar {
    temp_counter: u32,
}

impl AstDesugar {
    pub fn desugar_program(&mut self, program: &mut Program) -> CompilerResult<()>
    fn desugar_statement(&mut self, statement: &mut Statement) -> CompilerResult<()>
    fn desugar_expression(&mut self, expression: &mut Expression) -> CompilerResult<()>
}
```

**Features**:
- AST transformation utilities
- Integration points in compiler pipeline
- Extensible framework for future operators
- Recursive expression/statement desugaring

### 3. **Error Handling Patterns**

Comprehensive error propagation using Result and Option enums:

```kraken
// Manual error propagation with match
fn safe_operation(a: int, b: int) -> Result {
    let result: Result = divide(a, b);
    match (result) {
        Result::Ok(value) -> Result::Ok(value * 2),
        Result::Err(e) -> Result::Err(e),
    }
}

// Chained operations
fn chained_ops() -> Result {
    let r1: Result = divide(20, 2);
    match (r1) {
        Result::Ok(v1) -> {
            let r2: Result = divide(v1, 2);
            match (r2) {
                Result::Ok(v2) -> Result::Ok(v2),
                Result::Err(e) -> Result::Err(e),
            }
        }
        Result::Err(e) -> Result::Err(e),
    }
}

// Option handling
fn find_and_process(arr: [int], target: int) -> Option {
    let result: Option = find_value(arr, target);
    match (result) {
        Option::Some(index) -> Option::Some(index * 2),
        Option::None -> Option::None,
    }
}
```

```kraken
enum Result {
    Ok(int),
    Err(int),
}

fn divide(a: int, b: int) -> Result {
    if (b == 0) {
        Result::Err(1);
    } else {
        Result::Ok(a / b);
    }
}

fn test_result() -> Result {
    let result: Result = divide(10, 2);
    match (result) {
        Result::Ok(value) -> {
            puts("Success!");
            Result::Ok(value);
        }
        Result::Err(e) -> {
            puts("Error occurred");
            Result::Err(e);
        }
    }
}
```

### Option Handling

```kraken
enum Option {
    Some(int),
    None,
}

fn find_value(arr: [int], target: int) -> Option {
    let i: int = 0;
    while (i < 5) {
        if (arr[i] == target) {
            return Option::Some(i);
        }
        i = i + 1;
    }
    Option::None;
}

fn test_option() -> int {
    let arr: [int] = [1, 2, 3, 4, 5];
    let result: Option = find_value(arr, 3);
    match (result) {
        Option::Some(index) -> {
            puts("Found at index:");
            print_int(index);
            index;
        }
        Option::None -> {
            puts("Not found");
            -1;
        }
    }
}
```

### Mixed Result and Option

```kraken
fn complex_operation(arr: [int], target: int) -> Result {
    let opt: Option = find_value(arr, target);
    match (opt) {
        Option::Some(index) -> {
            let value: int = arr[index];
            let result: Result = divide(value, 2);
            match (result) {
                Result::Ok(v) -> Result::Ok(v),
                Result::Err(e) -> Result::Err(e),
            }
        }
        Option::None -> Result::Err(-1),
    }
}
```

## Technical Implementation

### Compiler Pipeline Integration

The `?` operator is integrated throughout the entire compiler:

1. **Lexer** (`tokenizer.rs`):
   - Emits `TokenKind::Question` for `?` character
   - Distinct from `Operator::Question` (reserved for future use)

2. **Parser** (`parser.rs`):
   - Postfix operator parsing in `parse_postfix()`
   - Creates `Expression::Try { expression }` AST nodes

3. **Type Checker** (`type_checker.rs`):
   - Validates inner expression type
   - Supports Result and Option type checking
   - Placeholder for future automatic unwrapping

4. **Monomorphization** (`monomorphization.rs`):
   - `infer_expression`: Type inference for Try expressions
   - `rewrite_expression_with_subst`: Type substitution
   - `scan_expression`: Generic type scanning

5. **Modules/Loader** (`loader.rs`):
   - Pattern rewriting for Try expressions
   - Private name mangling support

6. **IR Lowering** (`lower.rs`):
   - Lowers Try to inner expression
   - Placeholder for future match generation

7. **LLVM Codegen** (`llvm_backend.rs`):
   - Generates code for Try expressions
   - Currently passes through to inner expression

### AST Structure

```rust
pub enum Expression {
    // ... other variants
    
    /// Try expression: expr? (for Result/Option error propagation)
    Try {
        expression: Box<Expression>,
    },
    
    // ... other variants
}
```

### Desugaring Infrastructure

```rust
pub mod desugar;

pub struct AstDesugar {
    temp_counter: u32,
}

impl AstDesugar {
```

## Migration Guide

### For Existing Code

No breaking changes. All existing code continues to work as before.

### Using Error Handling Patterns

**Before** (without structured error handling):
```kraken
fn risky_operation(x: int) -> int {
    // No error handling
    x / 0;  // Runtime error!
}
```

**After** (with Result enum):
```kraken
enum Result {
    Ok(int),
    Err(int),
}

fn risky_operation(x: int, y: int) -> Result {
    if (y == 0) {
        Result::Err(1);
    } else {
        Result::Ok(x / y);
    }
}

fn safe_caller() -> Result {
    let result: Result = risky_operation(10, 2);
    match (result) {
        Result::Ok(value) -> Result::Ok(value),
        Result::Err(e) -> Result::Err(e),
    }
}
```
