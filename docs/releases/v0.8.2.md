# Kraken Language v0.8.2

**Release:** 0.8.2
**Published:** 2025-12-15

## Summary
FFI/stdlib hardening and production-readiness groundwork.

## Highlights
- **Single source of truth for stdlib/FFI declarations**: compiler typechecker + LLVM codegen stay consistent.
- **ABI-correct C boundary**: explicit widening/truncation rules (default signed for C `int`, with per-function overrides).
- **FFI safety policy**: trap on null for fallible owned pointer-returning libc calls (`malloc`, `fopen`, `realloc`).
- **Comprehensive integration tests**: compile+run smoke tests for libc strings/memory/env/file I/O, plus negative tests.
- **Platform notes**: documented macOS/Linux requirements and CI expectations.

## Breaking changes (if any)
- None.

## Changelog
### Added
- Compile+run FFI integration smoke tests: `strcmp`, `strlen`, `memcmp`, `malloc/free`, `getenv`, `setenv+getenv`, `fopen`, `fwrite`, `fread`, and consolidated file ops.
- Negative runtime tests: null-return traps for `malloc`, `fopen`, `realloc`.
- Documented compiler-enforced FFI/C boundary rules (ownership, nullability/trap policy, errno conventions, C `int` widening).
- Documented macOS/Linux platform notes and CI requirements (`docs/platform.md`).

### Changed
- Centralized libc/stdlib function metadata into a single shared table used by both typechecker and LLVM codegen.
- Made stdlib call lowering ABI-aware by inserting explicit argument casts and return widening at the call boundary.
- Added validation for the shared stdlib/FFI signature table and enforced it during `check` and `compile`.
- Optimized stdlib signature lookup in codegen by using a cached map instead of a linear scan; added a criterion benchmark.
- Updated examples to use deterministic, hardened FFI patterns.

### Fixed
- Fixed multiple silent FFI ABI mismatches by making widening rules explicit and consistent.
- Fixed LLVM stdlib call emission for `void`-returning functions.
- Fixed duplicate libc symbol declarations during codegen that could lead to renamed symbols and link failures.
- Fixed struct codegen invariants (struct registration order + idempotent struct type creation).
- Fixed example programs to parse/typecheck under current language rules.

### Removed
- None.

### Security
- Fail-fast behavior on null returns for fallible owned pointer-returning FFI calls reduces undefined behavior at the C boundary.

## Notes
- Verification: `cargo fmt --check`, `RUSTFLAGS="-D warnings" cargo test --workspace`, `RUSTFLAGS="-D warnings" cargo clippy --workspace --all-targets --all-features`.
- Examples: all `examples/*.kr` compile and run (some demos may return non-zero exit codes by design).
