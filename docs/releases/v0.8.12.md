# Kraken v0.8.12 Release Notes

**Release Date**: January 21, 2026

## Overview

Kraken 0.8.12 adds the **Generics Foundation**: generic functions and structs, explicit type arguments at call sites and struct literals, and a monomorphization pass that specializes generics into concrete copies. This release also introduces builtin generic container shims (`Vec<T>`, `Map<K, V>`) lowered during monomorphization to existing concrete runtime container types.

## Generics Foundation

### Generic Functions and Types

- Generic functions: `fn id<T>(x: T) -> T`
- Generic structs: `struct Box<T> { value: T }`
- Explicit call-site type arguments:
  - `id<int>(...)`
  - `Box<int> { ... }`

### Monomorphization (Specialization)

- Specializes generic functions/structs into concrete copies with mangled names
- Rewrites call sites and types so no generics remain after monomorphization

### Generic Call-Site Type Inference

- Infers omitted type arguments for generic function calls when possible
- Example: `id(123)` infers `T = int`

### Trait Constraints (MVP)

- Supports `where` clauses on generic functions and structs
- Enforces `where T: Clone` during monomorphization when specializing

## Generic Containers (Shims)

- `Vec<T>` lowered to:
  - `VecInt`
  - `VecString`
  - `VecBytes`
- `Map<K, V>` lowered to:
  - `MapStringInt`
  - `MapStringString`

## Bug Fixes
