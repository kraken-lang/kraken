# Kraken v0.8.21 Release Notes

**Release Date:** January 23, 2026

## Overview

Version 0.8.21 delivers **Turbofish Syntax and Type System Improvements** for the Kraken programming language. This milestone implements unambiguous generic type argument syntax, function type infrastructure, and enhanced type inference error messages, providing developers with better tools for working with generic code.

## Major Features

### Turbofish Syntax

**Unambiguous Type Arguments**
- Implemented `::<T>` syntax for explicit generic type arguments
- Works with function calls: `identity::<int>(42)`
- Works with struct literals: `Container::<int> { value: 42 }`
- Eliminates ambiguity with comparison operators in complex expressions
- Provides clear alternative to speculative `<T>` parsing

**Use Cases**
```kraken
// Function calls with turbofish
let x = identity::<int>(42);
let y = pair::<int, bool>(10, true);

// Struct literals with turbofish
let container = Box::<string> { value: "hello" };

// Regular syntax still works
let z = identity<int>(42);
```

### Function Type Infrastructure

**Parser Support**
- Full parsing of function types: `fn(int, string) -> bool`
- Function types in parameter positions
- Support for multiple parameter types
- Proper return type handling
- Integration with all compiler passes

**Type Checker Enhancements**
- Variables with function types can be called
- Proper type checking for function-typed parameters
- Support for higher-order function patterns
- Foundation for full higher-order function codegen

**Example Usage**
```kraken
fn apply_int(x: int, f: fn(int) -> int) -> int {
    return f(x);
}

fn main() -> int {
    let result = apply_int(5, |x: int| x * 2);
    return result;
}
```

### Improved Type Inference Error Messages

**Better Diagnostics**
- Clear error messages when type inference fails
- Contextual hints suggesting turbofish syntax
- Guidance on adding explicit type annotations
- Multiple resolution strategies provided

**Error Message Examples**
```
Cannot infer type arguments for generic function 'map'.
Hint: Argument types must be known. Consider:
1. Adding explicit type annotations to variables
2. Using turbofish syntax: map::<T>(...)
3. Providing explicit type arguments: map<T>(...)
```

## Usage Examples

```kraken
// Turbofish Syntax
fn identity<T>(x: T) -> T {
    return x;
}

fn main() -> int {
    // Explicit type with turbofish
    let x = identity::<int>(42);
    
    // Multiple type parameters
    let p = pair::<int, bool>(10, true);
    
    // Regular syntax still works
    let y = identity<int>(42);
    
    return 0;
}

// Function Types in Parameters
fn apply(x: int, f: fn(int) -> int) -> int {
    return f(x);
}

fn transform(data: int) -> int {
    return apply(data, |x: int| x * 2);
}

// Multiple Parameters
fn combine(a: int, b: int, op: fn(int, int) -> int) -> int {
    return op(a, b);
}

fn calculate() -> int {
    return combine(5, 3, |x: int, y: int| x + y);
}
```
