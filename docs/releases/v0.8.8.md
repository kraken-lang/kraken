# Kraken v0.8.8 Release Notes

**Release Date**: December 17, 2025

## Overview

Kraken 0.8.8 delivers the **Async + Concurrency** milestone. This release introduces async/await syntax, a lightweight runtime, and Go-style threading primitives for easy parallelism.

## New Features

### Async/Await Syntax
- `async fn` — declare asynchronous functions
- `await expr` — suspend execution until future completes
- State machine lowering (built on 0.8.7 IR foundation)

### Spawn & Join
- `spawn { }` — launch concurrent task blocks
- `join(handle)` — wait for single task completion
- `join_all(handles)` — wait for multiple tasks

### Thread Pool
- `pool_new(n)` — create pool with n workers
- `pool_spawn(pool, task)` — submit task to pool
- `pool_shutdown(pool)` — graceful shutdown

### Executor
- `executor_new()` — create async task executor
- `executor_spawn(exec, future)` — schedule async task
- `executor_run(exec)` — run until all tasks complete
- `executor_shutdown(exec)` — shutdown executor
- `block_on(future)` — run async from sync context

### Synchronization Primitives

#### Mutex
- `mutex_new()` — create mutex
- `mutex_lock(m)` — acquire lock
- `mutex_unlock(m)` — release lock
- `mutex_free(m)` — destroy mutex

#### Channel (Bounded)
- `channel_new(capacity)` — create bounded channel
- `channel_send(ch, value)` — send value
- `channel_recv(ch)` — receive value (blocking)
- `channel_close(ch)` — close channel

#### Atomics
- `atomic_new(init)` — create atomic integer
- `atomic_load(a)` — load value
- `atomic_store(a, v)` — store value
- `atomic_add(a, delta)` — atomic add, returns previous
- `atomic_sub(a, delta)` — atomic subtract, returns previous
- `atomic_cas(a, expected, new)` — compare-and-swap

### Cancellation & Timeouts
- `cancel_token_new()` — create cancellation token
- `cancel_token_cancel(token)` — signal cancellation
- `cancel_token_is_cancelled(token)` — check if cancelled
- `timeout(future, ms)` — time-bounded execution

### Timing
- `sleep_ms(ms)` — sleep for milliseconds

## Example

```kraken
fn worker(counter: bytes) -> void {
    let prev: int = atomic_add(counter, 1);
    printf("Worker done\n");
}

fn main() -> int {
    let counter: bytes = atomic_new(0);
    
    let h1: bytes = spawn { worker(counter); };
    let h2: bytes = spawn { worker(counter); };
    let h3: bytes = spawn { worker(counter); };
    
    join(h1);
    join(h2);
    join(h3);
    
    let final_count: int = atomic_load(counter);
    return final_count - 3; // 0 on success
}
```
