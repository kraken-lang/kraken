# Kraken v0.8.11 Release Notes

**Release Date**: January 21, 2026

## Overview

Kraken 0.8.11 adds the **Threading Foundation**: POSIX pthread-based threading primitives, mutex/condition variable synchronization, bounded channels, and function pointer support for thread spawning.

## Threading Foundation

### Thread Primitives
- `thread_spawn(fn)` — Spawn OS thread with function pointer
- `thread_join(handle)` — Wait for thread completion  
- `thread_detach(handle)` — Detach thread (no join needed)
- Function pointer syntax `&fn_name` for passing functions to threads

### Synchronization Primitives  
- `mutex_create()` — Create pthread mutex
- `mutex_lock(m)` — Blocking mutex lock
- `mutex_unlock(m)` — Unlock mutex
- `mutex_destroy(m)` — Cleanup mutex
- `condvar_create()` — Create pthread condition variable
- `condvar_wait(cv, m)` — Wait on condition with mutex
- `condvar_signal(cv)` — Wake one waiting thread
- `condvar_broadcast(cv)` — Wake all waiting threads
- `condvar_destroy(cv)` — Cleanup condition variable

### Channel Communication
- `channel_create()` — Create bounded channel (ring buffer with mutex/condvar)
- `channel_send(ch, val)` — Blocking send with mutex synchronization
- `channel_recv(ch)` — Blocking receive with condvar wait loop
- `channel_try_send(ch, val)` — Non-blocking send (returns bool)
- `channel_try_recv(ch)` — Non-blocking receive (returns 0 if empty)
- `channel_close(ch)` — Close channel and cleanup

### Thread Pool API
- `pool_new(n)` — Create thread pool struct with n worker slots
- `pool_spawn(p, fn)` — Submit work to pool (API foundation)
- `pool_shutdown(p)` — Graceful shutdown and cleanup

## Implementation Details

### Function Pointer Support
- Added `&fn_name` syntax for obtaining function pointers
- Type checker handles mangled function names
- Codegen supports C-callable function references
- Enables passing user functions to `thread_spawn`

### Channel Architecture
- Ring buffer implementation with capacity 16
- Mutex protection for concurrent access
- Condition variable for blocking operations
- FIFO ordering guarantees
- Proper cleanup and resource management

### Platform Support
- POSIX pthreads on macOS and Linux
- C calling convention compatibility
- Thread-safe memory management
- No global state or static initialization issues

## Example

```kraken
fn worker() {
    puts("Worker thread running!");
}

fn main() {
    // Create channel for communication
    let ch = channel_create();
    
    // Spawn worker thread
    let t = thread_spawn(&worker);
    
    // Send message to worker
    channel_send(ch, 42);
    
    // Wait for completion
    thread_join(t);
    
    // Cleanup
    channel_close(ch);
    puts("Thread example complete!");
}
```
