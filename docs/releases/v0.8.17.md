# Kraken v0.8.17 Release Notes

**Release Date**: January 22, 2026

## Overview

Kraken 0.8.17 delivers **Struct Patterns & Advanced Destructuring**: A comprehensive implementation of struct patterns, function parameter destructuring, and enum struct payloads. This release completes the pattern matching system with powerful destructuring capabilities across all language constructs.

## Struct Patterns

### Core Features

- **Struct Pattern Syntax**: `Point { x, y } -> { ... }`
- **Field Destructuring**: Extract struct fields directly in patterns
- **AST Representation**: `Pattern::Struct { struct_name, fields, partial }`
- **Type Checking**: Validates field existence, type compatibility, and completeness
- **LLVM Codegen**: Efficient field extraction and variable binding
- **Partial Patterns**: `Point { x, .. }` to ignore remaining fields
- **Field Shorthand**: `{ x }` means `{ x: x }`

### Examples

```kraken
// Basic struct pattern
match (point) {
    Point { x, y } -> {
        puts("Point coordinates:");
        print_int(x);
        print_int(y);
    }
}

// Partial struct pattern
match (point3d) {
    Point3D { x, .. } -> {
        puts("Only need x coordinate:");
        print_int(x);
    }
}

// Struct pattern with wildcard
match (point) {
    Point { x: _, y } -> {
        puts("Only care about y:");
        print_int(y);
    }
}

// Multiple struct patterns
match (shape) {
    Point { x: 0, y: 0 } -> {
        puts("Origin point");
    }
    Point { x: 1, y: 1 } -> {
        puts("Unit point");
    }
    Point { x, y } -> {
        puts("Other point");
    }
}
```

## Let Destructuring

### Core Features

- **Let Statement Patterns**: `let Point { x, y } = point;`
- **Tuple Destructuring**: `let (a, b, c) = tuple;`
- **AST Support**: `VariableDeclaration { pattern, ... }`
- **Type Checking**: Validates pattern matches initializer type
- **Variable Binding**: All pattern variables bound to environment

### Examples

```kraken
// Struct destructuring
let Point { x, y } = point;
print_int(x);
print_int(y);

// Tuple destructuring
let (first, second, third) = tuple;

// Nested destructuring
let ((a, b), c) = nested_tuple;

// Partial struct destructuring
let Point { x, .. } = point;
// Only x is bound, y is ignored
```

## Function Parameter Destructuring

### Core Features

- **Parameter Patterns**: `fn foo((x, y): (int, int))`
- **AST Change**: `Parameter.pattern: Pattern` (was `name: String`)
- **Tuple Parameters**: Destructure tuple arguments directly
- **Struct Parameters**: Destructure struct arguments directly
- **All Passes Updated**: Parser, type checker, monomorphization, IR, LLVM codegen
- **Pattern Name Extraction**: Helper functions for IR and codegen

### Examples

```kraken
// Tuple parameter destructuring
fn process_pair((x, y): (int, int)) -> int {
    x + y;
}

let result: int = process_pair((10, 20));
// result = 30

// Struct parameter destructuring
fn process_point(Point { x, y }: Point) -> int {
    x * y;
}

let p: Point = Point { x: 5, y: 7 };
let area: int = process_point(p);
// area = 35

// Multiple destructured parameters
fn distance((x1, y1): (int, int), (x2, y2): (int, int)) -> int {
    let dx: int = x2 - x1;
    let dy: int = y2 - y1;
    dx * dx + dy * dy;
}
```

## Enum Struct Payloads

### Core Features

- **Struct-Style Variants**: `enum Shape { Point { x: int, y: int } }`
- **AST Type**: `EnumVariantPayload` (Tuple or Struct)
- **Parser Support**: Parse both tuple and struct variant syntax
- **Type Checking**: Handle both payload types in pattern matching
- **Monomorphization**: Scan both payload types for generics
- **LLVM Codegen**: Construct and match both payload types

### Examples

```kraken
// Enum with mixed payloads
enum Shape {
    Circle(int),                    // Tuple payload
    Point { x: int, y: int },       // Struct payload
    Rectangle { w: int, h: int },   // Struct payload
}

// Pattern matching with struct payloads
fn describe_shape(s: Shape) -> int {
    match (s) {
        Circle(radius) -> {
            puts("Circle with radius:");
            print_int(radius);
            0;
        }
        Point { x, y } -> {
            puts("Point at coordinates:");
            print_int(x);
            print_int(y);
            1;
        }
        Rectangle { w, h } -> {
            puts("Rectangle dimensions:");
            print_int(w);
            print_int(h);
            2;
        }
    }
}

// Creating enum instances
let circle: Shape = Circle(5);
let point: Shape = Point { x: 10, y: 20 };
let rect: Shape = Rectangle { w: 30, h: 40 };
```

## Technical Implementation

### AST Changes

```rust
// Pattern enum extended
pub enum Pattern {
    // ... existing variants
    Struct {
        struct_name: String,
        fields: Vec<(String, Pattern)>,
        partial: bool,
    },
}

// Parameter struct changed
pub struct Parameter {
    pub pattern: Pattern,  // Was: name: String
    pub param_type: Type,
    pub is_reference: bool,
}

// Enum variant payload type
pub enum EnumVariantPayload {
    Tuple(Vec<Type>),
    Struct(Vec<(String, Type)>),
}
```

- Added field shorthand parsing: `{ x }` → `{ x: x }`
- Added partial pattern parsing with `..`
- Updated `parse_parameter_list()` to parse patterns

- Added struct field validation and completeness checking
- Updated match expression type checking for struct patterns

## Migration Guide

### Breaking Changes

**Parameter struct changed from `name: String` to `pattern: Pattern`**

If you have custom compiler passes or tools that access `Parameter.name`, update to:

```rust
// Old code
let param_name = param.name;

// New code
let param_name = match &param.pattern {
    Pattern::Identifier(name) => name.clone(),
    _ => "param".to_string(), // Handle complex patterns
};
```

### New Syntax Available

```kraken
// Struct patterns in match
match (point) {
    Point { x, y } -> { /* use x and y */ }
}

// Let destructuring
let Point { x, y } = point;

// Function parameter destructuring
fn foo((x, y): (int, int)) { /* ... */ }
fn bar(Point { x, y }: Point) { /* ... */ }

// Enum struct payloads
enum Shape {
    Point { x: int, y: int },
}
```
