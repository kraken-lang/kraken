# Kraken v0.8.7 Release Notes

**Release Date**: December 17, 2025

## Overview

Kraken 0.8.7 completes the **IR Integration** milestone. The compiler now has a full IR-based codegen path, desugar passes, state machine lowering for async, and expanded IO primitives.

## Bug Fixes

- Fixed `vec_int_pop` returning wrong element (was reading at index after decrementing length instead of before).

## New Features

### IR Backend Integration

- **`IrCodegen`** (`codegen/ir_codegen.rs`) - LLVM backend that consumes Kraken IR instead of AST
- Cleaner separation between frontend and backend
- Enables IR-level transformations
- Foundation for async state machines

### State Machine Lowering

- **`StateMachineLowering`** (`ir/state_machine.rs`) - transforms async functions into state machines at IR level
- **`AsyncAnalyzer`** - analyzes IR for await points and captured locals

### Desugar Passes

- **`Desugar`** (`ir/desugar.rs`) - IR transformation passes
- **`for` → `while`**: C-style for loops transformed to canonical while loops
- **`defer` lowering**: Defer statements collected and inserted at all function exit points (LIFO order)

### IO Baseline

New stdlib functions for basic I/O operations:

| Surface | Functions |
|---------|-----------|
| `io` | printf, puts, fread, fwrite, fgets, fputs, fflush |
| `fs` | fopen, fclose, fseek, ftell, feof, remove, rename |
| `process` | exit, getenv, setenv, unsetenv |
| `time` | sleep, usleep, time |

## Testing

- Added IR snapshot test infrastructure with golden files (`tests/ir_snapshots/`)
- Added 3 IR snapshot tests: `hello`, `arithmetic`, `if_else`
- **137 tests passing** (48 lib + 81 main + 8 runtime)
