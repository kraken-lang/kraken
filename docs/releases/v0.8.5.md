# Kraken v0.8.5 Release Notes

**Release Date**: December 15, 2025

## Overview

Kraken 0.8.5 introduces **Containers v1** - the first set of built-in container types with heap-allocated storage. This release adds five container types and 40 intrinsic functions for dynamic arrays and string-keyed maps.

## New Features

### Container Types

| Type | Description |
|------|-------------|
| `VecInt` | Dynamic array of `int` |
| `VecString` | Dynamic array of `string` |
| `VecBytes` | Dynamic array of `bytes` |
| `MapStringInt` | String-keyed map with `int` values |
| `MapStringString` | String-keyed map with `string` values |

## Implementation Notes

### v1 Limitations (to be addressed in future releases)

- **No bounds checking** on Vec get/set operations (unsafe like C)
- **No automatic resizing** for Maps (fixed capacity of 8 in v1)
- **Linear search** for Map operations (O(n) lookup)
- **delete clears entire map** in v1 (proper single-key delete deferred)
- `vec_int_pop` returns incorrect value (known bug, under investigation)

### Memory Layout

- **Vec types**: `{ data: *mut T, len: i64, cap: i64 }`
- **Map types**: `{ keys: *mut *mut i8, values: *mut T, len: i64, cap: i64 }`

## Upgrade Guide

No breaking changes from 0.8.4. Container types are additive.
