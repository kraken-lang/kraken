# Kraken v0.8.19 Release Notes

**Release Date:** January 22, 2026

## Overview

Version 0.8.19 delivers **complete closure and lambda infrastructure** for the Kraken programming language. This milestone implements full closure syntax, capture analysis, function types, and higher-order functions with comprehensive test coverage.

## 🎉 Major Features

### Closures & Lambdas (Complete)

**Closure Syntax**
- Expression closures: `|x, y| x + y`
- Block closures: `|x| { let y = x * 2; y + 1 }`
- Optional type annotations: `|x: int, y: int| -> int { x + y }`
- No-parameter closures: `|| 42`
- Move closures: `move |x| x + captured_value`

**Function Types**
- Function pointer types: `fn(int, int) -> int`
- First-class function values
- Type checking for function calls through pointers
- Full integration with type system

**Capture Analysis**
- Automatic detection of captured variables
- Distinguishes captured vars from closure parameters
- Supports capture by reference (default) and by value (move)
- Full pattern binding support (Tuple, Struct, EnumVariant, Or, etc.)
- 3 unit tests for capture analysis

**Higher-Order Functions**
- Functions accepting closures as parameters
- Functions returning closures
- Closure composition patterns
- Full type inference for generic closures

**Environment Generation**
- Unique environment struct names per closure
- Tracks captured variables for future allocation
- Integrated into IR lowering pass

## 💡 Usage Examples

```kraken
// Basic closure
let add = |x: int, y: int| -> int { x + y };
let result = add(5, 3); // 8

// Capture by reference
let multiplier = 10;
let scale = |x| x * multiplier;
let scaled = scale(5); // 50

// Move closure
let value = 42;
let moved = move |x| x + value;

// Higher-order function
fn apply(x: int, f: fn(int) -> int) -> int {
    return f(x);
}

let doubled = apply(21, |x| x * 2); // 42

// Closure composition
fn compose(f: fn(int) -> int, g: fn(int) -> int) -> fn(int) -> int {
    return |x| f(g(x));
}

let increment = |x| x + 1;
let double = |x| x * 2;
let composed = compose(double, increment);
let result = composed(5); // 12 (5 + 1 = 6, 6 * 2 = 12)
```
