# Kraken v0.8.13 Release Notes

**Release Date**: January 21, 2026

## Overview

Kraken 0.8.13 adds **String Operations & UTF-8 Handling**: 11 new string manipulation intrinsics covering trimming, searching, case conversion, replacement, and UTF-8 character operations. This release brings comprehensive string processing capabilities to the language.

## String Operations (11 Intrinsics)

### Core String Operations (8)

- `str_trim(s)` — Remove leading/trailing whitespace (space, tab, newline, carriage return)
- `str_contains(haystack, needle)` — Check if string contains substring
- `str_starts_with(s, prefix)` — Check if string starts with prefix
- `str_ends_with(s, suffix)` — Check if string ends with suffix
- `str_to_upper(s)` — Convert ASCII characters to uppercase
- `str_to_lower(s)` — Convert ASCII characters to lowercase
- `str_index_of(haystack, needle)` — Find first occurrence of substring (returns -1 if not found)
- `str_replace(s, old, new)` — Replace all occurrences of substring

### UTF-8 Handling (3)

- `str_is_valid_utf8(s)` — Validate UTF-8 encoding (basic validation)
- `str_char_count(s)` — Count UTF-8 characters (not bytes)
- `str_char_at_utf8(s, char_idx)` — Get nth UTF-8 character

## Deferred to 0.8.16

The following string operations are deferred to 0.8.16 for robust C runtime library implementation:

- `str_split(s, delim)` — Split string by delimiter
- `str_join(vec, sep)` — Join VecString with separator
