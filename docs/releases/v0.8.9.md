# Kraken v0.8.9 Release Notes

**Release Date**: December 18, 2025

## Overview

Kraken 0.8.9 delivers **Foundation Hardening** plus **Advanced Types**. This release fixes all concurrency placeholders, implements full enum support, and introduces borrowed view types, string manipulation, and debug bounds checking.

## Foundation Hardening

### Concurrency Primitives — Fixed
- `sleep_ms` — Now calls real `usleep()` syscall
- `mutex_*` — Real spinlock using LLVM atomic compare-and-swap
- `atomic_load` — Proper acquire memory ordering
- `atomic_store` — Proper release memory ordering
- `atomic_add/sub/cas` — Verified LLVM atomic RMW instructions

### Enum Implementation — Completex
- `enum` keyword and declaration parsing
- `EnumName::VariantName` construction syntax
- `::` (ColonColon) token for variant access
- `EnumType` with variant tag tracking
- Tag-based pattern matching discrimination
- Enum payload type extraction in match arms
- IR struct field access (proper field index lookup)
- IR return type tracking (no more Int placeholder)

## New Features

### Map Iteration
- `map_string_int_keys(m) -> VecString`
- `map_string_int_values(m) -> VecInt`
- `map_string_string_keys(m) -> VecString`
- `map_string_string_values(m) -> VecString`

### String Equality
- `str_eq(a, b) -> bool`
- `str_ne(a, b) -> bool`
- `bytes_eq(a, b) -> bool`

### Debug Bounds Checking
- `KRAKEN_DEBUG_BOUNDS=1` enables runtime bounds checking
- `vec_int_get` validates index against vector length
- Zero overhead when disabled (default)

### String Manipulation
- `str_len(s) -> int`
- `str_slice(s, start, end) -> string`
- `str_concat(a, b) -> string`
- `str_char_at(s, index) -> int`

### String View Type (`str`)
- Borrowed UTF-8 view with fat pointer: `{ ptr: *i8, len: i64 }`
- Foundation for zero-copy string operations

### Slice Types
- `SliceInt`, `SliceString`, `SliceBytes`
- Fat pointer representation: `{ ptr, len }`

## Example

```kraken
enum Color {
    Red,
    Green,
    Blue
}

fn main() {
    let c = Color::Red;
    
    match (c) {
        Color::Red -> {
            puts("Matched Red!");
        }
        Color::Green -> {
            puts("Matched Green!");
        }
        Color::Blue -> {
            puts("Matched Blue!");
        }
    }
}
```
