# Kraken v0.8.10 Release Notes

**Release Date**: December 18, 2025

## Overview

Kraken 0.8.10 delivers **Quality + Stdlib Expansion**. This release introduces comprehensive standard library modules for testing, math, random, logging, and formatting, along with advanced vector operations, compile-time profiling, and enhanced error diagnostics.

## New Stdlib Modules

### Test Framework
- `assert(cond)` — abort with message if condition is false
- `assert_eq(a, b)` — abort if values are not equal
- `assert_ne(a, b)` — abort if values are equal
- `test_pass(msg)` — print green [PASS] with message
- `test_fail(msg)` — print red [FAIL] and abort
- `test_skip(msg)` — print yellow [SKIP] with message
- `test_section(msg)` — print bold section header

### Math Stdlib
- `math_sqrt(x)` — square root
- `math_pow(x, y)` — power function
- `math_abs(x)` — absolute value for integers
- `math_floor(x)`, `math_ceil(x)`, `math_round(x)` — rounding
- `math_sin(x)`, `math_cos(x)`, `math_tan(x)` — trigonometry
- `math_min(a, b)`, `math_max(a, b)` — min/max for integers

### Random Stdlib
- `rand_seed(s)` — seed the random number generator
- `rand_int(min, max)` — random integer in range [min, max]
- `rand_float()` — random float in range [0.0, 1.0)
- `rand_bytes(n)` — generate n random bytes

### Log Stdlib
- `log_debug(msg)`, `log_info(msg)`, `log_warn(msg)`, `log_error(msg)`
- `log_set_level(level)` — set log verbosity level

### Format Stdlib
- `fmt_int(n)` — format integer to string
- `fmt_hex(n)` — format integer as hexadecimal
- `fmt_bool(b)` — format boolean to string
- `fmt_float(f, precision)` — format float with precision

## Vector Enhancements

### Capacity Management
- `vec_*_with_capacity(n)` — create vector with preallocated capacity
- `vec_*_capacity(v)` — get current capacity
- `vec_*_reserve(v, n)` — ensure capacity for n elements
- `vec_*_shrink_to_fit(v)` — reduce capacity to match length

### Advanced Mutation
- `vec_*_insert(v, i, val)` — O(n) insert at index with memmove
- `vec_*_remove(v, i)` — O(n) remove at index with memmove
- `vec_*_swap_remove(v, i)` — O(1) remove by swapping with last element

## Developer Experience

### Compile-Time Profiling
- `KRAKEN_PROFILE=1` environment variable shows phase timing
- Displays parse, typecheck, codegen, and link durations

### Runtime Benchmarks
- `bench_start()` — start benchmark timer
- `bench_end(start, name, iters)` — end benchmark and print results

### Enhanced Error Diagnostics
- `SourceSpan` — track error ranges, not just points
- `Diagnostic` — structured error with severity levels
- `DiagnosticHint` — suggestions for fixing errors
- Source context display with underlined error location

### CI Infrastructure
- GitHub Actions workflow (`.github/workflows/ci.yml`)
- Test suite, lint checks, and no-regressions gate

## Example

```kraken
fn main() {
    test_section("Math Tests");
    
    assert_eq(math_abs(-42), 42);
    test_pass("math_abs works");
    
    assert_eq(math_min(10, 20), 10);
    test_pass("math_min works");
    
    let v = vec_int_with_capacity(100);
    vec_int_push(v, 1);
    vec_int_push(v, 2);
    vec_int_insert(v, 1, 99);
    assert_eq(vec_int_get(v, 1), 99);
    test_pass("vec_int_insert works");
    
    vec_int_free(v);
    puts("All tests passed!");
}
```
